# Git Commit Style Guidelines

- Never use conventional commit prefixes (such as `feat:`, `fix:`, `chore:`, `refactor:`, `style:`, `test:`).
- Always write natural, human-like commit messages (e.g., "Update navbar styling and remove diagnostic badges", "Add fleet telemetry and model export options", "Improve benchmark data rendering").
- Keep titles concise, descriptive, and written in standard sentence/title casing without tags or robot prefixes.
